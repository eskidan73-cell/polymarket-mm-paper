# polymarket-mm-paper

Бумажный маркет-мейкинг на Polymarket: ничего не торгует, ключей и денег нет.
`mm_paper.py` раз в 10 минут держит виртуальные заявки (bid YES и bid NO
по mid ± 1 цент) на нескольких рынках и считает исполнения по реальной ленте
сделок (режимы `strict` - пессимистично и `touch` - оптимистично). Результат
(mark-to-market по mid) пишется в `mm_state.json` и `mm_log.jsonl`.
Награды и rebates не начисляются: оценка по полю `fee_eq` (доля комиссий,
которую заработали бы наши исполнения; реальный возврат это 15-25% от неё).
`probe.py` - одноразовая разведка API.
